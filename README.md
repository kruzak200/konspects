# Konspects

Локальная библиотека конспектов для macOS (Apple Silicon).  
Personal offline conspect library for macOS (Apple Silicon).

Сжимаете текст в **Merlin** сами → вставляете готовый конспект сюда → читаете офлайн и переписываете в тетрадь.  
Compress in **Merlin** yourself → paste the finished conspect here → read offline and hand-copy into a notebook.

**Без AI / без API-ключей.** Данные — обычные файлы в `Документы/Konspects` (`~/Documents/Konspects`).

Иерархия: **предмет → глава → раздел → подраздел**.

```text
Документы/Konspects/
  Предмет А/
    Глава 1/            ← папка главы
      chapter.json      ← разделы + подразделы + свои названия
      s_…/              ← папка раздела
        u_….md          ← текст подраздела
      assets/
        s_…/
          u_…/          ← картинки этого подраздела
```

## Требования / Requirements (Mac)

- macOS 12+ на Apple Silicon (M1–M4)
- [Node.js 20+](https://nodejs.org/) (LTS)
- [Rust](https://rustup.rs/) (нужен для Tauri; в репозитории `rust-toolchain.toml` просит **1.99** — `rustup` подхватит сам)
- Xcode Command Line Tools: `xcode-select --install`

## Установка и запуск / Install & run

В терминале (скопируйте по очереди):

```bash
git clone https://github.com/kruzak200/konspects.git
cd konspects
git checkout cursor/konspects-mvp-c221
npm install
```

### Режим разработки / Dev

```bash
npm run tauri dev
```

Откроется окно приложения. UI на русском.

### Сборка .app / Build

```bash
npm run tauri build
```

Готовое приложение будет в:

`src-tauri/target/release/bundle/macos/Konspects.app`

(и `.dmg`, если сборка его создала)

Можно перетащить `Konspects.app` в «Программы».

### Если сборка на Mac падала с `phf_macros` / `can't find crate`

Это уже исправлено в проекте (нельзя «strip»-ать proc-macros при release-сборке на новых macOS/Xcode).  
Обновите код и пересоберите **с чистого target**:

```bash
cd konspects
git fetch origin
git checkout cursor/konspects-mvp-c221
git pull origin cursor/konspects-mvp-c221
rustup show
npm install
cd src-tauri
cargo clean
cd ..
npm run tauri build
```

После успеха приложение будет здесь:

`src-tauri/target/release/bundle/macos/Konspects.app`

Не копируйте `.app` вручную, пока команда `npm run tauri build` не завершится без ошибок.

### Обновление уже установленного приложения

```bash
cd konspects
git pull origin cursor/konspects-mvp-c221
npm install
cd src-tauri && cargo clean && cd ..
npm run tauri build
```

Потом снова откройте новое `Konspects.app` из `src-tauri/target/release/bundle/macos/`.

Окно по умолчанию шире; зелёная кнопка macOS — развернуть / полный экран.

### Только фронтенд в браузере (удобно проверить UI)

```bash
npm run dev
```

Откройте `http://localhost:1420`. В браузере данные живут в `localStorage` (это превью). На Mac через `tauri` всё пишется в `Документы/Konspects`.

## Как пользоваться / How to use

1. Создайте **предмет**
2. Внутри создайте **главу**
3. В главе слева список **разделов**; у активного раздела раскрывается список **подразделов** (как 3.2.1 … 3.2.11):
   - **+ Раздел** — новый раздел с одним пустым подразделом
   - **+** у подразделов — новый подраздел
   - **∪** — режим объединения: отметьте 2+ мелких подраздела → «Объединить» (тексты склеятся, можно задать название)
   - клик по разделу / подразделу — переключение (чтение / правка)
   - название подраздела = **первая строка** текста (пока вы не зададите своё)
   - **Раздел…** / **Подраздел…** — своё имя; **Автоимя** — снова из текста
4. Вкладка **«Править»** — правка текущего подраздела (заголовки, **жирный**, *курсив*, таблицы, **картинки**)
5. **Таблицы** (когда курсор в таблице):
   - выравнивание текста в ячейке: **Яч. слева / центр / справа** (по умолчанию слева)
   - **Объединить** / **Разделить** ячейки (выделите несколько ячеек мышью)
   - тяните **внутренние** границы столбцов — общая ширина таблицы не меняется
6. **Картинка** — кнопка на панели или вставка из буфера (**Cmd/Ctrl+V**). Файл сжимается (длинная сторона ≤ 1600 px) и сохраняется рядом с подразделом
7. **Сохранить** — подраздел на диске
8. **«Читать»** — спокойный вид для тетради
9. **Экспорт в DOCX / PDF** — вся глава (все сохранённые разделы и подразделы, с картинками)
10. Можно закрыть приложение и открыть позже **без интернета**

### Файлы на диске / On-disk layout (v2)

```text
Документы/Konspects/
  Предмет/
    Глава/                      ← папка главы
      chapter.json              ← version: 2, разделы → подразделы, свои названия
      s_<id>/                   ← папка раздела
        u_<id>.md               ← Markdown подраздела
      assets/
        s_<id>/
          u_<id>/
            img_….jpg|png       ← картинки подраздела
```

Пример `chapter.json`:

```json
{
  "version": 2,
  "sections": [
    {
      "id": "s_abc",
      "customTitle": "3.2 Методы",
      "subsections": [
        { "id": "u_1", "customTitle": "3.2.1 Введение" },
        { "id": "u_2" }
      ]
    }
  ]
}
```

### Миграция со старых глав / Migration

При **первом открытии** главы приложение само обновляет файлы (безопасно для бэкапа Time Machine / копирования папки):

| Было | Станет |
|------|--------|
| `Глава.md` (один файл) | папка `Глава/` с одним разделом и одним подразделом |
| `Глава/chapter.json` v1 + `s_….md` рядом | `version: 2`, папка `s_…/u_….md`, картинки `assets/s_…/` → `assets/s_…/u_…/` |
| Раздел без подразделов | один подраздел с прежним текстом (и прежним автоименем из первой строки) |

Старые `s_….md` после переноса в папку удаляются. Если нужно откатиться — восстановите папку `Документы/Konspects` из бэкапа **до** первого открытия новой версией.

### Экспорт / Export

- **DOCX** — библиотека `docx` (заголовки раздела `#` и подраздела `##`, абзацы, жирный/курсив, таблицы, **картинки**)
- **PDF** — `jspdf` + шрифт DejaVu Sans (кириллица); JPEG/PNG/WebP вставляются в PDF
- Доп. системных зависимостей для экспорта **не нужно**
- Таблицы на диске — HTML внутри Markdown (объединения, выравнивание, ширины столбцов)
- Ограничения:
  - PDF: сложные таблицы могут переноситься упрощённо; для печати удобнее DOCX → Word/Pages
  - PDF: **GIF** обычно пропускается
  - Если файл картинки пропал с диска, в экспорте будет пометка «картинка не найдена»
  - Очень большие скриншоты при вставке ужимаются (≤ ~1600 px, ≤ ~6–8 МБ)
